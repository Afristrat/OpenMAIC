## Expérience source

L’échantillon part de trois propos d’un apprenant adulte :

1. « Dans mes projets, je sous-estime souvent les coûts récurrents lorsque je prépare le budget. »
2. « Dans le scénario tendu, j’ai classé le risque de trésorerie avant les autres risques. »
3. « Pour mon prochain budget, je testerai chaque poste avec une hypothèse basse et une hypothèse haute. »

Les trois voix sont Hanae, coach exigeante et concrète ; Youssef, analyste factuel ; et Salma, joker bienveillante.

## Points d’attention avant verdict

- Vingt graines dérivent de seulement trois événements synthétiques : une répétition perceptible est donc attendue ici, mais elle ne doit pas devenir la norme sur une session réelle plus riche.
- Les quatre analogies de Salma sont volontairement légères. Il faut vérifier qu’elles restent mémorables sans infantiliser un public adulte.
- Douze sollicitations et deux évaluations sur quatre-vingt-dix jours peuvent être jugées trop pressantes selon le contexte professionnel ; le verdict sur le contenu doit rester distinct du verdict sur la cadence.
